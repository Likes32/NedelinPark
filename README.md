# Nedelin Park

Одностраничный сайт-визитка дома-сферы у леса под Калининградом. Использует настоящее имя, настоящий логотип и настоящие цифры бизнеса — из инстаграма (**@nedelin_park**) и группы ВК (**vk.ru/nedelin_park**). Структура блоков ориентируется на референс-лендинг с Behance (архитектура секций, не пиксель-в-пиксель копия — свои цвета, шрифты, иконки и текст).

Открыть: **https://likes32.github.io/NedelinPark/**

Другие два варианта дизайна (вымышленное название «Затишье») остались рабочими:
- «Круг» — https://likes32.github.io/Zatishye/
- «Пар» — https://likes32.github.io/Zatishye-Par/

## Что настоящее, а что ещё нет

**Настоящее** (со слов самого бизнеса — из ВК-группы и инстаграма):
- название и логотип — герб с оленем и соснами, их собственный аватар в сообществах;
- цены: 13 000 ₽ пн–чт, 14 000 ₽ пт/вс, 15 000 ₽ сб;
- что входит в стоимость: купель без ограничений по времени, газовый гриль;
- доплаты: доп. гость 2000₽ взрослый / 1500₽ ребёнок, халат 600₽, дети до 3 лет бесплатно;
- телефон +7 (993) 734-34-74, адрес СНТ Электрон 192 (Калининград), telegram, instagram, vk;
- тон и формулировки — из их же постов («безлимитная купель», «единение с природой», подарочный сертификат).

**Ещё не подтверждено** — площадь дома, количество спален, точные фотографии интерьера (сейчас стоят подходящие по духу снимки с Unsplash, а не реальные фото дома).

## Что и почему убрано из Behance-референса

Референсный лендинг — рекламный сайт строительной компании (продаёт постройку баз отдыха под ключ), а не сайт самой базы. Часть блоков убрана, потому что под них нужны настоящие данные, которых на момент сборки не было — теперь часть из них уже восполнена реальными цифрами из ВК (раздел «Цена»):

| Блок в референсе | Решение | Почему |
|---|---|---|
| Отзывы клиентов с именами | убран | нет настоящих отзывов — подписывать выдуманный текст именем «клиента» нельзя |
| Правила проживания (заезд/выезд, депозит) | частично добавлено | из ВК есть реальные доплаты и лимит гостей — они в разделе «Цена»; точного времени заезда/выезда всё ещё нет |
| Калькулятор цены с датами | заменён на статичную таблицу цен + «написать в telegram» | реальные цены есть, но проверить свободные даты может только сам бизнес |
| Карта с точным пином | убрана | координат нет, только адрес текстом |
| Видео-блок | убран | нет настоящих видео |
| «Спасибо за просмотр» | не переносился | это финальный слайд Behance-презентации кейса, не часть самого сайта |

## Как поменять фотографии

Сейчас стоят подходящие по духу снимки с Unsplash — не настоящие фото дома. Чтобы поставить свои:

1. Положите фото в папку `photos/` рядом с `index.html`.
2. Замените адрес `https://images.unsplash.com/...` на `photos/имя-файла.jpg`.

## Как поменять тексты и цифры

Всё лежит в `index.html` обычным текстом. Раздел «Цена» и контакты — уже настоящие данные из ВК на дату сборки; при изменении цен просто отредактируйте `<ul class="price__table">`.
